# Mobile authentication setup

In Supabase, open **Authentication → URL Configuration → Redirect URLs** and add:

- Expo Go on the current development network: `exp://192.168.0.202:8081/--/auth/callback`
- Development or production build: `shoppy://auth/callback`

The Expo Go host is generated by Expo and can change when the computer changes networks or the server uses another port. If it changes, add the new `exp://<dev-host>:<port>/--/auth/callback` URL shown by the app's `makeRedirectUri` callback. The native build URL remains `shoppy://auth/callback`.

Add these values to the **Redirect URLs** allowlist only. Do not change the Supabase **Site URL** for mobile authentication. Google's OAuth provider should continue to use the Supabase callback URL shown in Supabase's Google provider settings; the app deep link is the post-sign-in destination.

Email confirmation and password-reset messages use the same app callback. The callback route exchanges PKCE codes or restores returned tokens; password-reset links open a screen to set the new password.
